# Audio Files Directory

Place your relaxing sound audio files here.

## Recommended files:
- `rain.mp3` - Rain sounds
- `ocean.mp3` - Ocean waves
- `forest.mp3` - Forest ambience
- `white-noise.mp3` - White noise
- `fireplace.mp3` - Fireplace crackling
- `cafe.mp3` - Cafe ambience

## File formats supported:
- MP3 (recommended)
- OGG
- WAV

## Where to get free sounds:
- https://mixkit.co/free-sound-effects/ (free, no attribution)
- https://pixabay.com/music/ (free, no attribution)
- https://freesound.org/ (requires attribution)

## Usage:
Once you add files here, update the URLs in `components/RelaxingSoundsPlayer.tsx` to use paths like:
- `/audio/rain.mp3`
- `/audio/ocean.mp3`
- etc.
